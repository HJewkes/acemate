# @acemate/cli

The `acemate` laptop CLI for probing the S10 over BLE: `npx acemate --help` from the repo root. `launch` is a dry run unless given `--fire`; `send` refuses OTA, calibration and court-profile writes. `--mock` runs any command against a built-in mock robot instead of Bluetooth. See the [root README](../../README.md#for-developers).
