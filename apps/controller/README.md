# controller

The Expo (SDK 55) Acemate Drive app for iPhone, also exported for the web at `/acemate/`. Install and usage are in the [root README](../../README.md).

Web build: `EXPO_BASE_URL=/acemate npm run export:web && EXPO_BASE_URL=/acemate npm run check:web`. Add `?probe=1` to the web URL for a Web Bluetooth capability panel.
